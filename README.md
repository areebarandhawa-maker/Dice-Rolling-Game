# 🎲 Dice Rolling Game

A graphical Dice Rolling Game developed using Python and Tkinter as part of my Python Development Internship – Month 1.

## ✨ Features

- Roll two dice
- Generate random values from 1 to 6
- Display both dice visually
- Calculate the total of both dice
- Interactive graphical interface
- Exit confirmation

## 🛠️ Technologies Used

- Python
- Tkinter
- Random Module
- Object-Oriented Programming

## 📚 Concepts Used

- Classes and Objects
- Functions
- Random Number Generation
- Conditional Statements
- GUI Development
- Event Handling

## ▶️ How to Run

Make sure Python is installed on your computer.

Run:

```bash
python dice_rolling_game.py
